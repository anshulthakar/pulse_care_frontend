React frontend for pulse_care hospital management system.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env.development` and set `VITE_API_URL`
3. `npm run dev -- --host`

## Build for production
1. Copy `.env.example` to `.env.production` and set `VITE_API_URL`
2. `npm run build`
3. Output is in `dist/`
